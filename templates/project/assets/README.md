# 图片与来源

| 文件 | 用途 / 图注 | 来源与许可 |
| --- | --- | --- |
| `cover.svg` | 默认封面占位图，待替换为真实项目截图 | 本仓库自绘模板 |

建议：

- 首图使用能够说明核心功能的截图，推荐 16:9 比例。
- 使用 `overview.png`、`workflow.webp` 等可读文件名。
- 每张图记录展示内容、来源和必要的许可信息；自己的截图可标注“本地复现截图 + 所用版本”。
- 替换封面后，在 `projects/catalog.json` 的 `cover` 字段填写相对子项目目录的路径，再同步首页。
- 在研究页用图注解释截图，避免只放图而没有说明。
