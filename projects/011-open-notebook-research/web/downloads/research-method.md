# 论文工具研究与验证方法

这里记录本次已经使用的方法，并提炼下一次可复用的标准。历史证据来自 008；“应当”或“建议”属于方法整理，不代表新增实验。

## 职责与成果分层

检索、下载、解析、生成和展示是不同环节。APD 负责采集与编排；本研究的 Europe PMC 适配提供水生毒理学输入；Open Notebook 组织来源和问答；MiniMax 生成文本；静态页面呈现已保存结果。Gradio 是 Python Web 界面工具，在原试跑中承担展示，并不是论文理解模型。

源库声明的能力、实际执行的请求、完整产物和质量核对分别记录。配置视频入口不等于已生成视频；HTTP 200 不等于回答完整；来源 ID 不等于 PDF 页码定位。

## 本次数据流

```text
关键词与日期范围 → Europe PMC REST 元数据 / JATS
  → 筛选 3 篇开放研究 → 期刊公开 PDF
  → 文件头 / 大小 / SHA256 → APD SQLite
  → Open Notebook 上传 → 文本提取 → SurrealDB 保存
  → 来源全文 → /api/chat/context → /api/chat/execute
  → Esperanto 适配 → MiniMax 官方接口
  → 回答 + 来源 ID + usage + finish_reason
  → 保存未经改写的原文 → 关键事实核对 → 静态结果页
```

本轮没有生成 embedding，来源全文直接进入上下文。它验证了小样本全文问答，不验证大规模向量检索、召回、重排或跨千篇文献的效果。PDF 实测输出是文本，不代表图像、公式或扫描件理解已验证。

## 1. 检索与输入验证

保存服务来源、查询时间、完整检索式、时间范围、命中数和筛选依据。本次检索式：

```text
(TITLE_ABS:"aquatic toxicity" OR TITLE_ABS:ecotoxicology OR
 (TITLE_ABS:zebrafish AND TITLE_ABS:toxicity) OR
 (TITLE_ABS:fish AND TITLE_ABS:PFOS))
AND OPEN_ACCESS:Y AND FIRST_PDATE:[2024-01-01 TO 2026-10-21]
```

查询时间 2026-10-21T15:45:18.989888+00:00；916 条命中和 30 条候选仅属于该时点与检索式。选择公开全文、许可明确、与鱼类 PFAS/PFOS 毒理相关的 3 篇原始研究。没有执行系统综述级多库检索、完整去重或筛选一致性评估。

下载后核对 PDF 文件头、字节数和 SHA256，登记 DOI、PMCID、作者、年与许可。云端输入再次比对哈希，确认分析的是同一份文件。错误页面即使有 `.pdf` 扩展名也不能算论文；索引中的作者摘要不能标为模型解读。

## 2. 应用与解析验证

| 层次 | 本轮证据 | 能说明什么 | 不能替代什么 |
| --- | --- | --- | --- |
| 环境 | 官方容器冒烟、固定镜像、版本 | 环境能运行容器 | 功能和用户入口 |
| HTTP 与认证 | health/UI 200，未认证 API 401 | 服务响应及认证边界 | 页面渲染与交互 |
| 导入 | 上传/读取 200、来源 ID、原文哈希 | 指定文件进入来源库 | 图表公式正确 |
| 抽取 | 字符数、标题和主要章节 | 正文可供模型使用 | 逐页无损解析、OCR |
| 持久化 | 来源和会话可再次读取 | 本次来源与回答已保存 | 跨平台恢复和长期可用 |

合成 PDF 只验证接口，不与真实论文成果混算。研究导入使用 `embed=false`、`transformations=[]`，将文本提取和生成分开。后续独立异步上传检查也没有调用模型。

## 3. 模型验证与失败对照

先选一篇，要求结构化中文解读、具体数据和来源，检查目标上下文，再进行多篇比较。本次单篇约 60,937 字符、综合约 174,111 字符；上下文 token 估算与实际 usage 分别记录。

| 运行 | 输入 tokens | 输出 tokens | 结果 |
| --- | ---: | ---: | --- |
| 原版单篇 | 21,212 | 8,192 | `length`，350 字符 |
| 低推理档位单篇 | 21,212 | 1,436 | `stop`，1,460 字符 |
| 低推理档位综合 | 54,717 | 1,828 | `stop`，3,056 字符 |

保留原版和适配版对照。此次仅针对 MiniMax-M3.1-Flash 与中国区地址传入 `reasoning_effort=low`、`max_retries=0`，保留 8192 上限。记录适配、原文件、差异和许可，先做不生成内容的请求构造检查，再执行生成。

低推理档位使本次回答完整，是几次实际运行的观察，不代表所有题目质量更高。本轮没有多模型盲评、重复采样或档位质量对照，不能给工具做普遍质量排名。

## 4. 水生毒理学内容核对

核对字段：物种学名、生命阶段、性别、污染物和混合比例、名义/实测浓度、单位、时长、盐度、对照与重复、终点、统计和不确定性。未报告的信息标为未报告。

本次代理根据论文做了关键字段抽查，详情见[质量核对记录](history-summary.md)，不等同领域专家逐句审定。

| 抽查 | 观察 |
| --- | --- |
| 斑马鱼条件 | 成年雌性、30 d、PFOS 50 μg/L、6:2 FTSA 50/500 μg/L 与原文一致 |
| 鲫鱼条件 | 96 h LC50 为 23.17 mg/L；21 d 为 0.1/0.5/1.0 mg/L，与原文一致 |
| C. variegatus 幼体 | 单独 PFOS 96 h LC50 为 1.97 mg/L，95% CI 1.64–2.16，与原文一致 |
| 混合设计 | 1:1 混合 1.99 mg/L 与固定 100 mg/L PFOA 条件下 3.10 mg/L 被单篇正确区分 |
| 物种译名 | 两份回答的中文俗名不可靠，应使用拉丁学名 |
| 综合外推 | “三种鱼均有肝脏或发育毒性”超出本轮共同证据 |

区分实验观察、作者解释和模型/研究者推断。通路富集或表达变化不自动证明因果机制；特定实验的拮抗不等于环境混合物普遍拮抗。比较论文时，先说明物种、剂量、时长和终点差异，再提出可比问题。

## 5. 可追溯展示

保留完整原文、文件哈希、来源映射、结束原因和实际用量。错误放在原文旁边指出，不静默修复再声称是原始结果。摘要、原始回答、研究代理核对说明明确区分。

静态页只读取整理好的资源，不提供实际上不能完成的上传或生成按钮。浏览不依赖云端进程持续存活，也不调用模型。以后若开放在线功能，应另行验收登录、上传、处理、提问、完整响应及刷新持久化。

## 6. 访问问题的证据边界

云机内成功与用户浏览器可访问是不同条件。端口需要实际映射，不能直接把云机 `127.0.0.1` 链接交给用户作为远程入口。

本次保存域名规则后的探测显示 ngrok 与 Microsoft Dev Tunnels 入口被代理返回 `403 Domain forbidden`，npm 对照正常。可说明当时这些目标被拒绝，不能确定所有隧道被禁、协议不兼容或环境发布错误就是原因。用户当时决定停止完整应用的访问部署排查，因此保留记录并停止此方向。随后另行授权静态研究网页发布；该发布提供已保存成果的阅读与下载，不恢复完整应用的上传和在线问答服务。

## 可复用的最小实验

1. 固定上游、模型、参数和论文清单，准备一篇公开文本型 PDF。
2. 核对文件、导入、抽取、来源读取及模型上下文。
3. 保存完整回答、结束原因、usage 与来源映射。
4. 抽查物种、单位、剂量、实验条件和结论范围，记录错误。
5. 通过后再增加论文，分别评估摘要、跨论文比较和引用。
6. 同时展示结果与失败样例；用户网页可达性单独验收。

这些是方法整理，不是下一轮已授权的执行计划。


## 2026-10-22 追加：从短回答到详细精读

本轮按用户对深度的要求，重新读取三篇完整主文，并渲染、目视核对关键方法页、统计表和结果图。新增三份逐篇分析及一份跨论文综合，索引见 [详细报告清单](detailed-report-index.json)。新增报告区分实验直接观察、作者解释与研究代理判断，保留样本来源、独立重复、名义/实测浓度、统计校正、未取得补充材料等限制。

对鲫鱼高剂量 DEG，正文与两幅图存在不同数字，保存两套原报值并交叉核算，不推断成因；对混合物 MDA，核对比较组和分母，不从摘要中抽取孤立百分比。对斑马鱼富集结果，区分原始 p、校正后 p 与 GSEA 探索阈值。关键数字经另一研究代理交叉复核。未重分析原始实验数据，未进行系统综述或荟萃分析。

网页每篇提供完整正文、目录、PDF 页码引用、核对记录和独立 HTML 阅读/打印页。打包校验同时检查正文副本、目录锚点、页码范围、PDF 哈希、离线 ZIP 和本地 HTTP 字节；该工程检查不替代科学审定。
