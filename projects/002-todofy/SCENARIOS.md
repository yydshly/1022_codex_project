# Todofy 使用场景

这些场景是基于固定版本能力设计的使用方案，帮助理解“如何使用、能得到什么、哪里有边界”。它们不是已经在本机录制或验收的操作结果。源码证据见 [原理分析](ARCHITECTURE.md)。

## 场景 1：每天知道先处理什么

**使用者与问题**：日常事项较多的个人用户，事情分散在消息、脑中和便签里，缺少当天的行动清单。

1. 用全局快速添加，先记录“完成周报”“预约体检”“回复客户”。
2. 为有期限的事项设置日期与优先级；没有日期的留在收件箱。
3. 早上打开今日视图，查看逾期与当天任务，将重要事项置顶。
4. 把大任务拆成小步骤，执行后完成，晚上调整未完成事项的日期。

**结果**：形成可查阅的当天待办，减少回忆和查找的成本。

**边界**：截止日期和优先级由使用者判断；系统不会自动根据任务难度排出最优顺序。日期展示也不保证那天有足够空闲时间。

## 场景 2：推进一个个人项目

**使用者与问题**：独立开发者、研究者或创作者，工作存在进行、阻塞、完成等阶段，按日期排列看不出推进情况。

1. 用“作品集”等项目标签归类，建立“收集素材、完成初稿、修改排版、发布”等任务。
2. 复杂任务拆成子任务，在看板中配置适合自己的工作列。
3. 开始时移到进行中，卡住时移到受阻并在备注写下原因。
4. 给进行中列设置 WIP 数量提醒，完成后拖入已完成。

**结果**：看板展示推进阶段，日历展示截止日期，任务详情展示步骤与相关信息。

**边界**：WIP 提醒不禁止超限；本次未发现团队指派、共享权限与完整依赖引擎，不能由个人看板推导成完整团队项目平台。

## 场景 3：学习与备考

**使用者与问题**：学生和自学者，计划停留在“每天学一点”，缺少可执行步骤与投入反馈。

1. 建立“复习一章”“练习听力”等任务，设置日期；稳定重复的内容使用重复规则。
2. 阅读、练习、整理错题放入检查清单，开始时启动番茄钟。
3. 查看当日与本周专注历史，在日志记录难点与下次需要调整的方法。

**结果**：把目标落实到步骤、节奏与回顾记录。

**边界**：重复任务原地推进到下一期，不能当成每次都有独立历史的习惯打卡。专注时长代表投入，不代表已掌握知识；日志摘要不自动评价学习质量。

## 场景 4：改善工作量估计

**使用者与问题**：自由职业者、写作者、设计师，经常低估工作耗时，导致计划过满。

1. 为“撰写初稿”预估 60 分钟；开始时启动该任务秒表。
2. 离开时暂停，回来继续；结束后保存会话。
3. 对比实际用时，在日志记录超时原因，为下次同类任务调整拆解与估计。

**结果**：用自己的实际记录改善时间估计。

**边界**：计时需要正确开始、暂停和结束；未暂停就退出，恢复后可能计入离开期间的时间。任务秒表不自动识别工作内容，也不等于工时开票或客户结算系统。

## 场景 5：离线工作与语音捕捉

**使用者与问题**：经常离线或偏好本机记录，希望断网时仍可管理任务，也想把口述变成草稿。

1. 网络可用时，按需下载本地语音引擎与多语言模型。
2. 平时离线使用任务、日历、日志和计时功能。
3. 录音结束后检查转写文字，再添加任务或保存日志。
4. 需要自己的多台设备保持一致时，再单独配置账号同步。

**结果**：核心记录与模型下载后的语音推理可在本机完成。

**边界**：语音性能取决于设备；中文转写不等于中文日期自动识别。语音质量尚待实测；启用云同步后，保存的任务或日志文本会按同步规则离开本机。

## 场景 6：在会议日历里看到任务

**使用者与问题**：平时在 Google Calendar 看会议，希望同时看到个人待办的截止日期。

1. 给待办设置日期，必要时加提醒时间。
2. 登录 Todofy 后单独授权 Google Calendar 集成。
3. 让应用把带日期任务推到专用日历，与其他日历一起查看；后续仍在 Todofy 编辑任务。

**结果**：Google Calendar 中同时可见会议与应用推送的待办。

**边界**：不会把会议导入 Todofy，也不是双向编辑；独立本地日程不推送。OAuth 构建配置、账号条件与网络会影响可用性，本次未连接实际账号。

## 需求与适配度

| 需求 | 适配判断 | 原因 |
| --- | --- | --- |
| 个人待办、今日计划、看板推进 | 高 | 对应核心任务模型与多视图 |
| 番茄钟与个人耗时回顾 | 高 | 有计时、预估对比与历史；需要正确操作 |
| 本机优先、日常离线记录 | 高 | SQLite 本地存储，账号可选 |
| 自己多台设备同步 | 有条件 | 需要官方 Pro 或自行配置后端，并理解同步冲突 |
| 中文口述录入 | 待实测 | 多语言模型提供可能性，准确率与速度未验证 |
| 中文自然语言自动排期 | 不应预设支持 | 快速添加采用英文日期与重复规则 |
| 团队派工、共享权限、依赖排程 | 不匹配本次确认范围 | 源码主线为个人任务与同账号同步 |
| 自动执行工作、生成最优日程 | 不匹配本次确认范围 | 系统负责组织、提醒和记录 |
| 完整双向日历、工时结算、习惯打卡历史 | 需要其他能力补足 | 相近模块不等于这些完整流程 |
