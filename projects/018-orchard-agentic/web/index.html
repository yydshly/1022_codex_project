WHAT WE UNDERSTAND

先把能力与价值说清楚。

正在载入完整研究摘要。Orchard Env 提供可控执行与环境管理；评测与训练需要相应模型、任务和资源。

01 / 理解与原理

模型思考，框架组织，
沙箱执行。

Orchard Env 是环境底座。整个 Orchard-Agentic 还包括评测工具、训练配方和数据，范围大于一个沙箱。

一套环境，三条使用路径

关系示意。Pod 内的轻量执行服务负责运行命令；模型接口与凭据由使用者另行配置。

02 / 能力边界

沙箱提供什么，
配套工具增加什么。

运行代码、修改文件、交互终端和受控联网属于执行底座；模型能力和任务成功判定来自另外接入的模型与任务协议。

需要按任务准备

Python、浏览器、项目依赖、数据、模型接口、凭据与评分规则。预装 Agent 工具不代表已经接入模型，也不代表具有任意任务的业务能力。

03 / DOCKER 对比

基础能力相通，
差别在管理工作。

Docker 本身也有 API、资源限制和网络能力。Orchard 将它们所在的容器生态组合成统一的任务服务，并提供 AI 研究配套。
