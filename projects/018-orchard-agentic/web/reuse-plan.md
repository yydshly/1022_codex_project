# 技术沉淀与后期扩展计划

这些是从固定源码归纳的复用建议，尚未抽取为独立模块。

## P0 · 统一沙箱后端契约

把创建、执行、文件、补丁和销毁抽成稳定接口，业务层可适配本地 Docker 或远程服务。

| 输入 | 输出 | 验收条件 |
| --- | --- | --- |
| 任务镜像、命令、资源与网络预算 | 状态、stdout/stderr、退出码、文件与补丁 | 同一任务在不同后端产生可解释的状态和可追踪制品。 |

[固定源码参照](https://github.com/microsoft/Orchard-Agentic/blob/bd8da32b3a075128700caab75bbc491fb6fdc16e/orchard_env/orchard_env/client/sandbox_client.py)

## P0 · 生命周期与预算治理

沉淀任务状态、超时、取消、心跳、TTL、幂等清理与失败分类。

| 输入 | 输出 | 验收条件 |
| --- | --- | --- |
| 创建请求、心跳、取消与时限 | 就绪/完成/失败/回收记录 | 失败与重复清理不遗留环境，任务取消和重试有明确语义。 |

[固定源码参照](https://github.com/microsoft/Orchard-Agentic/blob/bd8da32b3a075128700caab75bbc491fb6fdc16e/orchard_env/orchard_env/orchestrator/sandbox_manager.py)

## P0 · 轨迹与干净评测协议

保留原始事件与标准化轨迹，绑定补丁、评分、模型、框架和任务版本。

| 输入 | 输出 | 验收条件 |
| --- | --- | --- |
| 执行事件、补丁、测试与版本 | 可重评分的结果、日志和制品清单 | 区分任务失败和环境故障；相同预算与版本下比较成绩。 |

[固定源码参照](https://github.com/microsoft/Orchard-Agentic/blob/bd8da32b3a075128700caab75bbc491fb6fdc16e/orchard_eval/README.md)

## 分阶段落地

### 一：单机任务协议

先用 Docker + 脚本跑一个真实需求，约定输入、镜像、时限、输出、日志与测试。验收：失败、超时、取消有记录，制品可定位、环境可回收；够用时可停在此阶段。

### 二：远程环境服务

出现统一接口或跨机器需求后接入 Orchard Env，配置集群、网络策略、资源预算和生命周期。验收：远程创建、传输、执行、导出与清理可追踪，并在目标配置验证边界和容量。

### 三：批量评测证据

锁定任务、模型、框架、镜像、推理预算和重试协议，保留原事件与标准轨迹。验收：补丁可重评分，环境故障与任务失败分开，中断评测可继续未完成任务。

### 四：任务环境与训练

按需加入浏览器、文档或工具镜像，再接奖励器与训练器。验收：先小规模验证任务、观测、动作、结果、数据许可与评分闭环，再扩并发或训练。


## 可扩展场景

| 类型 | 场景 | 可复用 | 新增前提 | 状态 |
| --- | --- | --- | --- | --- |
| 基础执行 | 远程代码执行与数据处理 | 命令、文件、预算与自动回收 | 语言与数据工具镜像、制品存储、上层用户权限 | 可复用底座，需任务适配 |
| 评测与工程 | AI 自动修复与回归检查 | Agent 环境、Git 补丁、干净测试和日志 | 项目依赖、验收测试、模型与失败处理 | 可复用评测流程，需仓库适配 |
| 评测与工程 | 模型 / Agent 框架对比 | 一致环境、任务与轨迹规范 | 固定模型、框架、镜像、推理预算与统计口径 | 适合批量研究 |
| 任务扩展 | 浏览器多步任务 | 并行沙箱、网络策略与轨迹基础 | 浏览器镜像、观察/动作工具、视觉模型、成功判定和网站故障处理 | 需额外任务环境与工具 |
| 任务扩展 | 编程教学与自动评分 | 每题独立环境、测试、时限与回收 | 题库、评分器、账户权限和课程流程 | 需业务层与题库 |
| 训练研究 | Agent 交互数据工厂与训练 | 多轮执行、失败分类、环境与评测一致性 | 数据治理、奖励器、模型、训练器与计算资源 | 需模型、数据与 GPU 预算 |
| 后续能力 | 同一状态分叉探索多条路径 | 当前可先独立重跑不同尝试 | 完整状态快照、暂停/恢复、分叉和前缀共享仍在上游路线图 | 后续研究，非现成功能 |

完整状态快照和分叉属于后续路线图。统一身份、计费、多租户业务授权与任意恶意代码的强隔离也不能视为当前仓库已完整提供的产品能力。
