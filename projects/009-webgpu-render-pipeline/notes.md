## 影响判断的发现

1. `surfelGi` 与 `probeLive` 默认关闭。默认主路径偏向静态缓存，不能泛称完整实时 Lumen。
2. `tilePool.ts` 已用 CPU 半精度块 + `writeTexture`，而虚拟纹理文档仍描述 stage 1a 全量 GPU store。文档不是当前实现的唯一事实源。
3. 主场景导入 `entities/water/index.ts`；水实验室导入 `physicalWater.ts`，后者有 FFT 和专门光学追踪。这些能力需按实际接入点描述。
4. 依赖清单缺少直接使用的 React 包及 Vite React 插件；vendor、TSX 配置和独立页面接线不完整。
5. 根 `index.html` 只加载主应用。作者目录中的 `/labs/water/`、`/labs/fiber/` 和 `/pipeline` 还不能认定已经装配好。
6. 没有仓库级许可证；作者性能文档和概念目标也不能替代当前设备实测。
