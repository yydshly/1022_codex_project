    03 / HOW IT WORKS

    把“这种感觉”，拆成可以执行的步骤。

    风格规则决定画面怎么组织，图像模型负责创作，Python 负责处理与校验，Electron 负责桌面运行。
    这个库把它们安排成有先后顺序、可单独返修的流程。

      04 / WHY IT IS USEFUL

      值得带走的，是一套创作方法。

      把审美经验写成规则，
      让一张图的创作经验可以继续复用。

      让风格有依据，
      让修改有落点，
      让角色有延续。

      01 / 表达

      给产品一个小故事

      实物提供可信质感，手绘动作提供轻松的叙事。适合餐饮、生活方式内容与社交海报的视觉探索。

      02 / 协作

      把“差一点感觉”说具体

      把线条、字形、留白和材料关系拆成可检查要求。反馈可以定位到一个字形、一段轮廓或一个动作。

      03 / 延展

      同一个角色，走向不同媒介

      确认后的角色身份同时约束产品互动图与桌宠动作，连接静态内容和轻互动体验。

      可沉淀的技术

      从风格经验，到可复用的创作与运行工具。

      风格与参考协议

      构图、线条、字形与材料规则 → 可切换风格的 Skill 和提示模板。

      分阶段生成与局部返修

      底图与标题分离、先线后色、锁定通过项 → 可记录和定向修改的创作流程。

      角色身份约束

      固定轮廓、脸、四肢和材料 → 供海报、姿态和动画共用的角色身份档案。

      透明动画资产工具链

      帧条、锚点、贴地、manifest 和 ZIP 校验 → 可重复运行的处理、审核与打包工具。

      事件行为与共享运行器

      阶段完成事件、优先级、冷却、角色包分离 → 可导入不同角色的轻互动运行层。

      以上已有上游规则或代码依据，可继续提炼为独立模块；本研究尚未将它们封装为通用 SDK。

      05 / KNOW THE EDGES

      用之前，先知道它依赖什么。

      创作依赖

      图像能力来自宿主

      仓库提供 Skill、参考规则和工具。实际生成需要可用的图像模型；单独安装 Python 依赖还不能完成海报创作。

      质量边界

      一致性需要人工看图

      中文、主体细节、透明边缘和角色动作都可能偏离要求。上游设有形象与动作两次确认，格式校验覆盖文件结构和部分可量化约束。

      使用条件

      静态创作与桌面运行分开

      海报和静态角色无需 Electron；运行桌宠才需要对应环境。风味小怪兽使用 schema v3，要求运行器 3.1.0 或更高。
