能力
把 Agent 的回复和部分运行状态转成可见的角色反馈。
原理
预制字符画配合 JavaScript 动画；状态控制动作，文字驱动气泡和嘴型。
效果
等待、思考、工作、回复四类状态，温和基础表情，支持点头与字符音效。
价值
让等待有反馈、对话有稳定形象，为聊天助手和任务展示提供可复用表达层。

01 / 状态怎么表现

让“正在做什么”看得见。

等待输入：温和的基础表情，加上眨眼和轻微动作。

依次体验：等待 → 思考 → 工作 → 回复。

02 / 情绪能表达多少

温和是底色，动作带来神态。

当前的表达主要来自眼睛、眉形、嘴型和姿态。
每种能力的范围，都放在这里。

现有表情
◕ ◡ ◕

温和、友好的基础面孔

一套 warm 基础表情贯穿对话。轻微笑意、自然眨眼和点头，形成陪伴感。

现有动作表达
◔ · ◔

专注、斟酌、正在回应

看向别处像在思考，低头像在工作，嘴型变化像在说话。状态事件驱动姿态，回复文字驱动气泡和嘴型。

尚未内置
喜 · 怒 · 哀 · 乐

丰富情绪，需要继续扩展

当前没有完整的开心、悲伤、生气、惊讶表情组，也不会根据回复含义自动判断情绪。

可扩展：更多表情图案 + 情绪事件映射

画面表达的是预先定义的动作与表情。角色没有真实情绪；文本嘴型是近似动画，字符音效也不等于语音朗读。

03 / 换一句话，看它回应

把你的文字，交给角色来表现。

完整播放或模拟流式输出，体验气泡、嘴型和节奏。

播放时可切换上方状态，或点击“停止”。

04 / 给 Agent 增加一层表达

回复和状态进来，角色动作出来。

自己的 Agent 负责处理任务。把必要的状态和回复传过来，就能复用这个角色。
