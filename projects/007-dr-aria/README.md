# 007 · dr-aria · 角色效果与表达图鉴

这个子项目用一张总结图与交互网页，汇总代码绘制的 ASCII 角色、动作效果、状态切换、价值和情绪表达边界。它可视化的是 Agent 的回复和部分运行状态；核心是事件驱动动作、文字驱动气泡与嘴型。原库是带人设、技巧卡和记忆的 Claude 聊天应用，我们抽取的是角色展示层。

## 我们的理解摘要

| 维度 | 结论 |
| --- | --- |
| 能力 | 将 Agent 的回复和部分工作状态，转成可见的角色反馈。 |
| 原理 | 预制字符网格与颜色构成形象，JavaScript 控制动画；状态事件驱动姿态，回复文字驱动气泡与嘴型。 |
| 效果 | 四类运行状态、一种温和基础表情，配合点头、逐字回复和可选字符短音。 |
| 价值 | 让等待有反馈、对话有稳定形象，提供可复用、可嵌入的表达层；接其他 Agent 需适配。 |

可扩展到聊天助手、学习陪练、产品演示和任务进度，实际体验需按场景验证。它呈现的是可观察的输出与状态，Agent 的推理和工具能力仍由原系统负责。总结图的网页加载、放大、关闭、下载和手机布局已检查，见 [本轮验证](summary-verification.json)。

## 可以看到什么

角色由字符网格、颜色网格和 JavaScript 动画绘制。外观是预先定义的，眼睛、嘴型、头发、笔和环境细节按程序变化。

| 状态 | 展示效果 |
| --- | --- |
| 等待输入 | 眨眼、视线变化、轻微呼吸，保持倾听姿态 |
| 思考中 | 看向别处，眼睛和嘴部做等待动作 |
| 工作中 | 低头、笔移动，表现正在处理事情 |
| 正在回复 | 文字逐字出现，嘴型随文字变化，可选字符音效 |

此外可以单独点头、停止播放、输入自己的展示文字，或播放模拟的 Claude / Codex 事件。字符音效是短音，不会朗读句子；中文嘴型是近似动画。

页面提供“一键看完整表现”和情绪表达汇总；接入代码与事件记录按需展开。已通过八组本地浏览器检查，见 [验证记录](verification.json)。

## 情绪表达能做到哪一步

目前只有 **1 种 `warm` 温和基础表情**。眨眼、点头、视线和嘴型让角色显得有反应，但它们主要表达工作状态。

上游没有现成的喜、怒、哀、乐表情集，也没有根据回复语义自动判断情绪的功能。网页明确展示这些边界，不把“思考中”或“嘴在动”计作额外情绪。

## 本地打开

在仓库根目录运行：

```bash
python projects/007-dr-aria/scripts/package_web.py
python -m http.server 8047 --bind 127.0.0.1 -d projects/007-dr-aria/web
```

打开 [http://127.0.0.1:8047/](http://127.0.0.1:8047/)。需要现代浏览器；通过 HTTP 加载，不直接双击 `file://` 文件。

这是静态展示，不需要模型账户或 API key，不消耗 Claude / Codex 额度，也没有连接你的 Agent。后续接入可复用现有角色组件，详见 [integration.md](integration.md)。
