01 / 从任务定位

给谁看，想留下什么？

写清用途、观众和希望产生的感受，再补一个要避免的感受。“自然展览，希望亲近生命，避免冰冷”比“高级感”更具体。

02 / 把感受落到画面

要安静还是有力，亲近还是疏离？

用设计能量与观看距离辅助选择，再落实到光线、冷暖、主体尺度、留白和字体。数值是创作标尺，不能测量人的真实情绪。

03 / 由成图校准

第一眼的感受，符合目标吗？

检查情绪中心是否清楚，光色与材质是否一致，转化是否服务故事。冷色不必然孤独，粒子也不必然科技；以下起点都可以改。
