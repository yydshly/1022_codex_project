# 从情绪档案，到作品与视频

核心方法是：**用艺术意图统领作品，用具体视觉与听觉要求指导 AI 实现。**

最新实际视频见[《留一点位置》](ai-film-direction.md)，使用Seedance 2.0生成，已成为[网页视频入口](http://127.0.0.1:8033/003-algorithmic-sublime-poster/#ai-film)。下文保留早期《夜香》代码合成预演的制作记录。

情绪是目标，氛围是体验，风格是稳定的表达规则。写实、水墨、粒子和拼贴都可以作为语言；原有 Algorithmic Sublime 的真实实体、计算关系、识别中心和模块化标题继续作为一种风格保留。进入其他媒介时，需要把同一意图转译成该媒介能执行的要求。

## 三种创作用途

| 形式 | 指导重点 | 交付材料 |
| --- | --- | --- |
| 海报、插画、摄影、封面 | 主体关系、观看距离、光色、构图、材质与留白 | 创作总纲、画面要求、提示词和检查依据 |
| 品牌系列、展览、连续内容 | 跨作品固定的配色、材质、字体、转化关系，以及各幅作品允许的变化 | 系列规则、逐幅差异、参照和避免项 |
| 广告、产品概念片、动画、短片、MV | 情绪起点、转机事件、结尾余味，以及镜头、动作、节奏、声音和衔接 | 情绪走向、分镜、逐镜指令、一致性规则和返修要求 |

通用流程：用途与观众 → 目标与避免感受 → 故事与风格规则 → 画面或分镜要求 → 生成与制作 → 成品校准与返修。

情绪档案可以指导各阶段的选择。一个标签无法代替完整分镜；声音也需要与画面指向同一感受。表达强烈不等于特效密度更高。

## 实际演示：《夜香 · 给孤独一个回应》

打开 [网页视频演示](http://127.0.0.1:8033/003-algorithmic-sublime-poster/#motion-demo)。这是已完成的15秒MP4，1280×720、24fps、H.264视频与48kHz双声道AAC声音。支持播放、暂停、原生全屏、声音开关、时间定位、三张分镜定位和说明同步；可复制完整指令并下载TXT、分镜JSON和MP4。

| 时间 | 情绪作用 | 具体执行 |
| --- | --- | --- |
| 0–5秒：独处 | 安静与距离，避免恐怖和绝望 | 冷灰蓝空间、完整瓶身、左侧留白、极缓慢推进、低频空间声 |
| 5–10秒：回应 | 希望通过一个微小事件进入 | 暖光逐渐进入，信号沿瓶底与玻璃轮廓生长，约6.6秒与8.9秒出现柔和音符 |
| 10–15秒：余温 | 保留独处，留下希望 | 暖意停在局部，冷色空间继续保留；标题渐显，和声与尾音衰减 |

五条固定规则：保留同一瓶身与识别中心；维持冷灰空间与留白；计算信号服从玻璃轮廓与接触关系；保持慢推轴线；末段标题与同一情绪中心协调。三个阶段都保持较低的数据密度。

## 制作来源与能力边界

先使用内置ImageGen实际生成一张原创关键画面，完整英文指令见 [关键画面指令](assets/motion/night-signal-keyframe-prompt.txt)。原始PNG保留不变，工具未返回模型版本；共一次调用、无返修。画面额外出现右侧建筑开口、山景和较明显的暖色反射，实际制作保留这些结果，通过视频调色组织暖色进入的时间。

随后使用原创Python合成器制作确定性的慢推、冷暖变化、轮廓信号、文字和声音，再由FFmpeg编码为MP4。声音由程序原创合成，不含外部音乐采样。未调用文生视频或图生视频模型，没有演示主体连续动作、真实三维绕拍或视频模型的时序稳定性。

这是本研究扩展的动态概念验证，上游海报仓库没有新增视频生成能力。逐镜指令可进一步用于视频模型、动画制作或拍摄；需要按实际生成结果修正时序、主体和声音。分镜与成片的机器可读记录见 [完整分镜](assets/motion/night-signal-brief.json) 与 [素材及哈希清单](assets/motion/manifest.json)。

## 如何积累自己的作品风格

每次保存意图、固定规则、指令、成品、实际感受、偏差出现的时刻，以及具体返修。保留认可的作品与反例，逐步说明哪些规则跨作品延续、哪些表达随任务变化。不用一个总分代替观看反馈，也不把某个情绪标签当作结果保证。

返修格式可以是：“第几秒出现什么偏差；把哪项光色、镜头、动作、数据或声音改成什么；哪些主体与风格规则继续保留。”系列作品同样可以定位到具体某幅。

## 可复现环境与命令

本次环境：Python3.10、Pillow、NumPy、FFmpeg6.1.3；实际依赖版本记录在验证文档。中文与拉丁字体使用Windows系统的Microsoft YaHei和Consolas，仅渲染成片，不分发字体文件。

在仓库根目录运行：

~~~powershell
python projects/003-algorithmic-sublime-poster/scripts/render_motion_study.py
python projects/003-algorithmic-sublime-poster/scripts/package_web.py
python projects/003-algorithmic-sublime-poster/scripts/package_web.py --check
~~~

渲染需要Pillow、NumPy以及PATH中的FFmpeg/FFprobe。可用 --chinese-font、--latin-font 指定当地已安装的字体；--work-dir 指定中间文件目录，默认在被忽略的 _site/ 下。--stills-only 只输出三个时间点。运行网页和常规打包只需要Python标准库，不要求安装渲染依赖。

最终影片已随网页打包，访问者无需重新渲染、连接账号或调用生成服务。浏览器不会根据情绪档案实时生成新视频。修改生成或渲染结果后，应同步更新素材清单中的哈希和实际版本记录。
