# 候光：让情绪发生在时间里

2026-10-22，接在静态情绪生成验证之后，补充三条可播放、可下载的12秒有声影片。在线预览路径为 `003-algorithmic-sublime-poster/#motion-emotions`。

用艺术意图统领作品，用具体视觉与听觉要求指导实现。进入视频后，要求需要增加**人物关系、事件、等待、动作、镜头、剪辑、声音与结尾**，不能只有一组颜色形容词。

三片共享场景、主体类别、构图起点、16:9、1280×720、24fps、12秒、基础雨声与低密度线条。多个表达条件一起变化，是三份导演方案的演示，不是单变量实验。情绪标签是作者意图，没有独立观众验证。

网页支持选片、播放/暂停定格、声音开关、时间拖动、三阶段定位、同步分镜说明、复制或下载对应导演指令、下载完整方案JSON与各片MP4。默认关闭声音，不自动播放；建议先看无声画面，再加入声音比较。原来的静态验证、21份情绪档案、原风格编辑器与《夜香》视频均保留。

## 制作来源和边界

内置ImageGen实际生成两张原始PNG，原样保存，模型版本和种子未返回：

- [雨夜场景](assets/motion-emotions/rain-shelter-plate.png)：1672×941，[实际指令](assets/motion-emotions/rain-shelter-plate-prompt.txt)。工具原文件 `exec-fe8a49f8-8de7-44e0-8efd-401a300c16af.png`。实际输出亭子比要求更大、位置更高，带海岸与山景；制作按实际构图定位人物。
- [透明四姿态人物](assets/motion-emotions/walker-sprites.png)：1983×793 RGBA，透明通道范围0–255，[实际指令](assets/motion-emotions/walker-sprites-prompt.txt)。工具原文件 `exec-c9e14961-3fb8-439b-a557-db9821fe0ed1.png`。四姿态变化有限，并不是严格的运动捕捉序列。

两张原图在最终影片渲染时适配画幅、按透明区域提取姿态并复用。程序播放四姿态步态、移动与镜像人物，合成雨、水波、接地反射、路面光、镜头及稀疏短线；声音为本研究原创数值合成，没有使用外部音乐。三张封面从最终MP4的8.8秒提取。

这是**AI素材＋人工导演方案＋程序动画与声音**。视频模型调用次数为0。两人复用同一人物外观；转身、停步、接地和步态存在二维动画局限；镜头为平面画幅变换，没有重建真实三维空间。当前成片示范时间表达的组织方式，不能作为AI视频指令遵循能力、身份保真或情绪成功率的证据。

完整分镜计划见 [study.json](assets/motion-emotions/study.json)，在本次编码前写出；生成来源、哈希见 [manifest.json](assets/motion-emotions/manifest.json)。三份 `*-video-direction.txt` 是后续可交给视频模型的输入草案，明确标记**尚未执行**，不能与两张素材实际执行的图像生成指令混淆。

## 后续如何指导AI和返修

先写用途、观众与希望/避免的感受，再写“起点 → 转机事件 → 余味”。每段补充谁做什么、持续多久、镜头怎样看、声音何时进入，以及哪些风格规则贯穿全片。

审片时优先描述偏差出现的时刻和具体原因。例如：“希望版8秒时两人仍相隔太远，把并肩站定提前到7秒；保持场景、雨夜和整体颜色不变。”这比“更有希望、更高级”更便于执行和比较。

可以用于影像提案、广告或MV气氛板、动画预演、情绪与声音教学。要进一步验证AI情绪引导，需要实际调用视频模型、保留全部输出、固定可控条件并收集独立观看反馈；本次没有完成这一步。

## 复现

依赖Python3.10、Pillow11.3、NumPy2.2.6、FFmpeg6.1.3。网页运行不需要这些渲染依赖。

~~~powershell
python projects/003-algorithmic-sublime-poster/scripts/render_emotion_films.py
python projects/003-algorithmic-sublime-poster/scripts/package_web.py
python projects/003-algorithmic-sublime-poster/scripts/package_web.py --check
python scripts/project_catalog.py check
~~~

完整当前渲染器已导出三条各288帧视频，视频和音频均完整解码通过。音频48kHz立体声，峰值分别0.1968/0.1515/0.1736，未削波。输出H.264/AAC，支持网页原生播放；预览服务继续使用支持Range请求的 `serve_web.py`。
