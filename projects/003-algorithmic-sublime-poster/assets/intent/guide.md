# 以情绪和艺术意图为核心的AI创作总纲

用艺术意图统领作品，用具体视觉与听觉要求指导AI实现，再依据实际结果校准。

本研究基于上游风格规范与提示词组织方法提炼并扩展；情绪总纲、跨媒介模板与案例复用方案为本研究整理，不是上游原文或模型训练能力。

## 如何交给AI使用

1. 填完【占位项】，把参考文件逐个注明角色并实际附上。
2. 先让AI解释意图与具体要求的对应；指出冲突、缺失和取舍，再形成完整指令。
3. 把完整指令交给可用生成工具；生成后保存准确提交文本、原件、实际参数与偏差。
4. 图像、视频、代码预演与未执行方案分别标明；无法生成时明确尚未生成。
5. 复用方案是从案例整理的指导材料，实际提交指令另存；修改复用方案不代表产生新作品。
6. 情绪是创作目标，作品感受需要观看反馈；本组案例没有独立观众命中率或因果结论。

情绪决定表达方向；风格规定稳定规则；粒子、光色、镜头等手段服务具体任务。感受与手段没有一一对应：冷色也可能宁静，温暖不只依靠暖色。

[完整JSON包](templates.json)同时包含21份情绪档案、原有主风格固定规则与3份风格旁支，可整包交给AI；案例图片/视频与主体素材仍须实际附上。

## 原有主风格的固定规则

- 真实可辨认的实体与计算结构共同存在，保留识别中心。
- 选择与主题相关的计算隐喻，实体与数据有清楚的边界或空间关系。
- 字符、像素、点云或扫描结构沿轮廓、透视、动作或光线组织。
- 模块化大标题参与构图，少量等宽标注辅助，不遮住识别中心。
- 光色服从艺术意图，疏密与留白有层级，不强制黑底或无关HUD。

```text
避免的感受：【容易跑偏的相邻感受】

3 / 主体、关系与表达依据

让感受成立的关系或事件：【疏离如何通过距离表现；接纳如何通过行动发生】
识别中心与必须保留项：【面部 / 姿态 / 产品外形 / 关键物品 / 原有文字】

4 / 风格档案
固定规则：【跨作品保留的材质、配色逻辑、构图或视觉关系】
本次允许变化：【主体、局部色彩、布局、转化区域等】
实现手法与强度：【写实 / 水墨 / 拼贴 / 字符 / 粒子等；作用在哪里，服务什么意图】
如果采用原“算法崇高”风格，补齐：真实实体与计算结构的关系、沿轮廓/透视/光线组织的数据、模块化大标题、识别中心与疏密层级。若采用其他风格，明确新的固定规则。

5 / 素材角色与具体视觉要求
素材角色：【逐个标明：主体身份参考 / 风格参考 / 情绪参考 / 完整编辑目标；无素材则写文字生成】
光线与色彩：【方向、软硬、明暗层级、冷暖与暖色面积】
空间与构图：【景别、主体比例、留白、观看距离、视线与空间关系】
材质与细节：【皮肤、织物、玻璃、纸面等如何可感知】
避免项：【与目标冲突的装饰、风格或动作】
参考作品说明的是对应关系，不能替代当前任务；未提供的主体图片不得假设已提供。

6 / 图片交付
画幅与尺寸：【比例与目标尺寸】
标题与文字：【逐字文本、字体语气、位置；无字则明确无字】
视觉焦点：【第一眼看哪里；转化范围与方向；哪些区域保持完整】
系列规则（可选）：【各图共享什么；每张允许改变什么】

7 / 执行与检查
先给出简短的“意图 → 画面依据”说明，再整理一份可直接交给图像模型的完整指令。
按可用工具生成或编辑；工具不可用时明确只交付方案、尚未生成。
实际生成后保存准确指令、输入角色、工具/模型及返回参数、原图与轮次；对未知信息标为未知。
先隐藏情绪标签看第一感受，再检查主体、风格、文字与细节。指出哪些具体线索支持目标、哪些仍有歧义；不能把目标写成已验证的观众感受。
发现偏差时，记录具体位置与可见证据，下一轮只改最关键的问题，说明继续保留什么。
```

### 视频 / 从疏离到被接纳

风格归属：艺术意图方法延伸

艺术意图：被看见、被接纳，结尾留下克制的温暖。

如何落地：等候 → 移伞邀请 → 目光回应 → 同行；同一雨巷与光色贯穿。
