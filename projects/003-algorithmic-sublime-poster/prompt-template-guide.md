# 以情绪和艺术意图构造提示词

核心是：**用艺术意图统领作品，用具体视觉与听觉要求指导模型实现，再依据实际结果校准。** 原库提供风格规范、设计约束与提示词组织方式，本研究把情绪总纲扩展到图片、视频和定向返修。情绪档案与视频方法并非上游自带的新模型能力。

[网页创作模板](http://127.0.0.1:8033/003-algorithmic-sublime-poster/#intent-template)提供可编辑的完整指令、案例载入与导出。

## 总纲结构

用途与观众 → 目标与避免感受 → 主体关系或转机事件 → 固定风格与可变项 → 具体视听要求 → 实际生成与证据 → 检查返修。

情绪定义希望观众产生的感受；艺术命题说明作品表达什么；风格是跨作品保留的规则；光色、粒子、材料与镜头是实现手段。感受与手段没有一一对应，目标要通过具体关系或事件成立。例如，被接纳可以转成“主动移伞—目光回应—共同前行”。

替换【占位项】，把主体与参考作品逐个标明身份、风格、情绪或完整编辑目标的角色，再实际附给AI。让AI先解释艺术意图与具体要求的对应、指出冲突和取舍，再组织完整生成指令。生成后保留准确提交文本、原始输出、返回参数与偏差，逐步积累自己的风格档案。

## 图片与视频案例

- 《风有形》：温柔与生长 → 暖纸、柔侧光、真实花瓣与有方向的边缘纸片。这是材料旁支。[实际指令](assets/warm-bloom-prompt.txt)。
- 《之间》：孤独与距离 → 灰青大空间、小瓶身、稀疏轮廓采样。一轮尺度返修由约39%降至约24%画幅高度，仍保留字体和重绘偏差。[实际首轮](assets/validation/02-bottle-solitude-prompt.txt)、[实际返修](assets/validation/07-bottle-solitude-repaired-prompt.txt)。
- 《留一点位置》：从疏离到被接纳 → 等候、移伞、回应、同行，持续同一雨巷与光色。实际视频动作提前，后段背影较多，声音内容未完成听觉审片。[准确实际指令](assets/ai-film/shared-space-prompt.txt)、[原始视频](assets/ai-film/shared-space-original.mp4)。

网页“载入复用方案”使用的是事后整理的中文材料，不是历史准确指令，也没有生成新作品。模板切换保留各自草稿；载入案例或恢复空白替换所选类型文本；刷新清空，用户可下载保存。草稿JSON明确generated=false、actual_new_output=null，并指向相应历史记录，返修草稿指向实际返修指令。

## 维护与边界

`scripts/prepare_intent_guide.py`是唯一模板源，生成5个指导文件；整合JSON中的情绪与旁支档案从既有文件原样读取。`scripts/package_web.py`新增这5项及既有海报来源记录，总计110项，复制不改变原媒体。

网页只在浏览器内存中编辑与导出文本，没有新增模型调用或自动生成后端。所有图片与视频继续复用既有原始文件；原风格、21份情绪档案与旧实验保留。现有案例没有独立观众命中率或因果结论，目标感受不能被预写成已验证的观看结果。
