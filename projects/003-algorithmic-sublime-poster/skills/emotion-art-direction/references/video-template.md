# 视频创作模板

按实际任务裁剪；【】为待填内容。

你是本次创作的艺术指导。用情绪与艺术意图统领作品，把抽象感受转成具体、可执行的画面要求。先读完总纲，再组织生成指令；发现冲突时指出冲突并给出取舍建议，不擅自改掉必须保留的内容。

1 / 用途与观众
交付形式与用途：【海报 / 插画 / 摄影 / 短片；在哪使用】
观众与观看条件：【给谁看；观看距离、屏幕或停留时间】

2 / 情绪与艺术意图（统领后续选择）
希望观众感受到：【主情绪；用一句具体感受描述】
副情绪与结尾余味：【可留空；只补充一处关系】
避免的感受：【容易跑偏的相邻感受】
艺术命题：【这件作品想表达什么，为什么值得看】
表达力度：【含蓄 / 清晰 / 强烈；不自动等同于更多特效】

3 / 主体、关系与表达依据
具体主体与环境：【谁 / 什么；在什么空间】
让感受成立的关系或事件：【疏离如何通过距离表现；接纳如何通过行动发生】
识别中心与必须保留项：【面部 / 姿态 / 产品外形 / 关键物品 / 原有文字】

4 / 风格档案
固定规则：【跨作品保留的材质、配色逻辑、构图或视觉关系】
本次允许变化：【主体、局部色彩、布局、转化区域等】
实现手法与强度：【写实 / 水墨 / 拼贴 / 字符 / 粒子等；作用在哪里，服务什么意图】
如果采用原“算法崇高”风格，补齐：真实实体与计算结构的关系、沿轮廓/透视/光线组织的数据、模块化大标题、识别中心与疏密层级。若采用其他风格，明确新的固定规则。

5 / 素材角色与具体视觉要求
素材角色：【逐个标明：主体身份参考 / 风格参考 / 情绪参考 / 完整编辑目标；无素材则写文字生成】
光线与色彩：【方向、软硬、明暗层级、冷暖与暖色面积】
空间与构图：【景别、主体比例、留白、观看距离、视线与空间关系】
材质与细节：【皮肤、织物、玻璃、纸面等如何可感知】
避免项：【与目标冲突的装饰、风格或动作】
参考作品说明的是对应关系，不能替代当前任务；未提供的主体图片不得假设已提供。

6 / 视频交付与时间表达
画幅、目标时长、声音与输出：【例如16:9、10秒、有声；以实际返回参数核对】
情绪走向：【开头的状态 → 引发变化的事件 → 结尾余味】
分镜或连续镜头计划（按总时长调整，起止连续）：
- 【起止秒】感受目标：【】；人物可见行动与回应：【】；空间关系：【】
- 【起止秒】转机事件：【】；表演与停留时间：【】；相机与衔接：【】
- 【起止秒】结尾行动：【】；保留的余味：【】；如何结束：【】
摄影与连续性：【镜头数量、景别、机位、运动路径、角色外观、天气、光色与遮挡关系】
动作与物理关系：【重心、手和道具、接触点、布料；正常速度还是明确的慢动作】
声音：【环境声、动作声、空间变化、音乐出现时刻、对白/旁白有无与音量层级】

7 / 执行与审片
先给出“意图 → 行动/空间/节奏/声音”的对应，再整理可直接交给视频模型的完整指令。
需要实际生成视频时使用视频生成工具；静态图、代码预演和分镜方案分别标明制作方式。
实际生成后保存准确指令、输入、模型、返回参数与原始视频，区分计划秒数和实际发生时刻；未知信息标为未知。
完整看片并分别检查人物关系、时序、身份、材质、镜头和声音。未听片时不得声称声音要求已全部实现。
记录偏差发生的具体秒数及修正要求。情绪是目标，是否传达需要观看反馈，不预设成功率。
