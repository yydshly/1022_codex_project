# 从观看到返修：动态情绪V2

2026-10-22，在《候光》三条编排影片上优化人物与时间表达，保留全部V1原片，补充V2和网页复盘工具。本轮没有新增图像或视频模型调用，仍使用原先两张ImageGen素材。

## 本轮实际修改

| 方面 | V1 | V2 |
| --- | --- | --- |
| 人物比例 | 合成前约91px高，远景中偏小 | 主要人物144px、来人134px，细节与人物关系更可见 |
| 姿态对齐 | 每个姿态按自己的外接框居中，可能横跳 | 按上部透明轮廓的重心对齐头部位置，统一脚底基准 |
| 行走与停步 | 固定9fps轮换姿态，轨迹与帧序分开 | 每走78px推进一轮四姿态；6.8秒起减速，8.2秒停住，逐渐混入站姿 |
| 两人关系 | 同一素材、相同高度和衣色 | 仍复用同一人物素材，以身高和衣色调节区分；不宣称独立人物身份生成 |
| 环境与接地 | 基础反射和全屏雨线 | 接触阴影、随高度衰减且轻微扰动的反射、亭内后层雨线减弱；均为二维合成近似 |
| 声音 | 固定间隔的脚步模拟 | 按行走距离39px的标记安排脚步；三组原始合成音频RMS统一为0.032 |

这是针对可观察制作问题的修改，不代表情绪质量已被量化证明。四姿态与二维平面仍限制自然度、转身和空间运动。相机仍为画幅变换，雨线遮挡按画面区域近似。

## 网页的使用流程

1. 在单片播放器选择情绪与V1/V2版本。切换版本保留当前时刻并暂停，方便比较人物比例、动作与停步；单片切换则从头开始。
2. 展开“同步对照”，用共同时间轴播放、暂停或定位三片。默认全部静音，可只听其中一片，避免声音叠加。浏览器在偏差超过约0.12秒时进行追赶，属于近似同步；不是逐帧测量工具。
3. 展开“个人复盘”，记录实际感受、具体时刻、偏差、希望怎样改，以及这轮只改哪一项。
4. 网页据此组织针对当前版本的返修草案，保留艺术意图、固定规则和检查问题。复制或下载后，可以交给后续制作、拍摄或AI工具执行。

记录按“版本＋影片”分别保留在当前页内存，刷新清空，不上传。可以导出全部个人记录JSON。页面已显示情绪目标，因此记录明确标记intentVisible=true、independentBlindStudy=false；无自动情绪识别、成功率评分或模型调用。生成的返修要求标记尚未执行，不能当作新的成片。

推荐描述：“8秒时来人停得太突然，请提前0.8秒减速，停步后保留3秒共同等待，其他色调和镜头保持。”它说明问题发生在哪里、改什么和怎样检查，比“更有希望”更容易用于下一轮。

## 适用场景与积累价值

适合概念片与动画预演、导演沟通、视觉与声音教学、AI创作前的方案明确，以及生成后的逐镜复盘。每次把意图、指令、版本、实际偏差和返修要求一起保留，逐渐积累自己的风格和情绪表达经验。

当前样片是“AI素材＋导演方案＋代码动画与合成声音”。下一步若要验证视频模型是否能执行，需要另行实际生成、固定可控条件、保留所有结果并收集独立观众反馈；这轮没有完成该验证。
