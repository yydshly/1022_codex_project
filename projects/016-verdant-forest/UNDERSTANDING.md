# 我们的理解：从植物素材到自然场景制作能力

Verdant Forest 把程序化植物、空间布局、实时渲染和相机交互组合成一片可探索的温带森林。对我们的价值同时存在于素材、生成方法、运行方法和最终体验四个层次。

研究范围固定为 `bb724d84fb683b8f1dea790c3e56f2ffadeb051e`。网页使用已有的 `assets/understanding-overview.png` 作引导图，原始浏览器画面另行保留。

## 能力与效果

| 能力 | 访客实际看到或操作什么 | 实现支撑 |
| --- | --- | --- |
| 程序化植物 | 立体树干与枝叶、蕨类、草、灌木和野花 | 曲线分枝、管状网格、弯曲折叠叶片与固定随机种子 |
| 森林组织 | 密集又有层次的植被，小径、根部和地表细节 | 地形高度、间距与避让规则、空间分区和模型变体 |
| 自然动态与光影 | 树枝摆动、叶片颤动、树冠阴影与林间光雾 | GPU 顶点位移、同步深度材质、方向阴影、接触遮蔽和单次空气散射 |
| 漫游与镜头输出 | 自由探索、升降观察、30 秒五镜头导览与逐帧画面 | 相机控制、预设轨迹、固定时刻渲染和采集编码脚本 |

7,155 棵树是作者记录的场景总量；近景与远景使用不同细节。作者的 1080p、24 fps 影片逐帧采集，不能据此判断交互帧率。本研究已看到作者托管原版正常渲染，未开展 GPU 性能基准测试。

## 可以沉淀的技术

这里的“可沉淀”表示值得进一步提炼的模块。当前已完成源码分析、独立教学实验和研究网页，以下模块尚未打包成通用工具。

| 技术 | 建议沉淀的接口或产物 | 具体意义 | 当前依据 |
| --- | --- | --- | --- |
| 参数化植物生成 | 植物类型、形态参数、种子与几何输出接口 | 通过参数获得变化，减少逐个手工建模；后续可评估 GLB 导出 | `trees.js`、`botanical-refinement.js` |
| 确定性空间布局 | 地形采样、密度、间距、小径和障碍避让规则 | 同样输入可复现布局，也能为不同场景调整分布 | `math.ts`、`vegetation.ts` |
| 密集植被运行 | 共享网格、实例变换、空间分区、LOD 与预算配置 | 把细节留给近处，对远景采用成本更低的表示 | `vegetation.ts`、`distant-trees.ts` |
| 风动材质 | 时间、位置相位和高度权重，以及相应阴影变形 | 让大量植物协调运动，减少逐对象 CPU 动画工作 | `materials.ts` |
| 自然光影合成 | 场景深度、太阳阴影、接触遮蔽与空气散射的组合 | 获得根部接触感、树冠明暗和林间空气层次 | `volumetrics.ts`、`engine.ts` |
| 确定性镜头与采集 | 镜头配置、固定时间采样、帧校验和编码约定 | 在相同构图下比较材质变化，形成可重复的画面输出 | `cinematic.ts`、配套捕获脚本 |

建议先从“少量植物生成 + 一小块地形 + 实例化与 LOD”开始提炼，记录目标设备的初始化时间、帧率、显存与绘制预算，再加入复杂风动和体积光。评价标准应来自目标设备实测，而非场景总对象数或编码播放帧率。

## 后期可扩展的使用场景

| 场景 | 可借鉴什么 | 后续需要补什么 |
| --- | --- | --- |
| 自然主题展厅 / 教育展示 | 植被层次、自由漫游、局部观察与镜头导览 | 科普内容、交互标注、无障碍操作与低性能设备方案 |
| 庭院 / 旅宿 / 景观导览 | 自然环境布置、路径与建筑周围的植物组织 | 建筑或场地模型、尺度与碰撞、导览路线、移动端加载 |
| 交互叙事网页 / 品牌体验 | 景深层次、氛围、镜头与可探索空间 | 自有视觉内容、事件与叙事节奏、资源加载和用户操作设计 |
| 自然氛围短片 / 镜头创作 | 固定种子、可调整构图、风动与逐帧采集 | 镜头编辑、采集编码、声音制作及素材授权 |

这些方向是研究建议，并非上游已经实现的完整产品功能。植物资产导出、场景编辑器、生态生长模拟和商业化交付系统不在当前成果范围内。

## 与已有 009 光照研究的关系

009 关注间接光、环境补光、软阴影及多类表面受光。016 补充植物结构、密集植被组织、自然运动和森林空间表达。两者可形成一套互补的学习路线。

工程整合需要单独处理渲染后端、材质与着色器接口、坐标和资源管理，不能假定把两个项目直接拼接即可运行。目前没有完成直接代码整合。

## 使用边界

- 固定版本没有仓库级许可证；对应纹理与 Three.js 的声明不能代替整体授权。完整改造或分发前应确认权利范围。
- 自适应分辨率和 LOD 是性能取舍手段，不能保证任意设备流畅。
- 研究总览图由 ImageGen 参考真实运行截图制作；效果证据以保留的原始浏览器图和作者台账为准。
- 本研究网页的五个 Canvas 实验是教学示意，不执行上游的完整渲染流程，也不构成上游性能测量。
