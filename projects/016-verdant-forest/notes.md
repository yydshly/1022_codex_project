- 目标：用中文网页解释能力、展示真实效果、拆解原理，并说明实际复用价值。
- 上游 SHA：`bb724d84fb683b8f1dea790c3e56f2ffadeb051e`，通过 GitHub Git Tree API 重新核对。首次对话时的版本与本轮一致。
- 研究输入：README、package.json、engine / vegetation / trees / botanical-refinement / math / materials / volumetrics / cinematic / config 及作者验证记录。
- 上游依赖：Three.js 0.180、React 19、Vinext / Vite，Node.js 要求 >= 22.13.0。这些属于原版应用；本研究网页无 npm 依赖。

- 数量：浏览器采样记录中的树木数为 7,155。植被总生成量、每帧可见量、三角形统计和绘制调用不可混为一谈。

- 技术判断：三维叶片、实例化、LOD、空气散射与资源生命周期协作是主要学习价值；程序化布局不等于植物生长或生态模拟。
- 页面设计：深绿森林首屏与浅色研究正文；效果图集、按需原版、五个 Canvas 原理实验、渲染链路、三种价值与证据来源依次展开。
- 五个实验均为独立编写的教学图解：不加载 Three.js、不执行上游 shader、不用教学图冒充原库效果。
- 发布路径：`016-verdant-forest/`。素材先打包到 `web/assets/`，根汇总器沿用现有编号站点构建；尚未验证公开部署时不填写 demo_url。

- 完成三种宽度的响应式与交互检查，未发现页面横向溢出或已加载的损坏图片。
