# 014 · Seijaku：住宅导览、能力与同类项目对比

**Seijaku 是基于 Three.js 的日式住宅交互网页：滚动镜头连续穿行室内外，结合四季联动、材料特写、构造拆解、水面和环境声。** 本研究对比 Kage、Sublevel Studio 及已有住宅扩展，重点研究季节材质状态、构件展开与投影标注、资源预热和按需绘制，可扩展到住宅旅宿导览、展馆与结构教育、产品工艺展示及空间作品集。

## 重复基础与新增价值

Kage 已覆盖滚动镜头、章节、程序建筑、氛围和图像叠层。Sublevel 已覆盖空间状态、可玩物件、CanvasTexture 与 DOM 作品集。我们在 `0904 / 080` 的原创住宅扩展中，还完成了庭院入户、六站房间图、平面图、自动导览、有限环绕，以及相机／门／灯光／文字／URL 同步。

Seijaku 的平面图、房卡、房间导览和三维网页联动主要属于组织和完成度增强；Sublevel 的街机、篮球和动态 CRT，Kage 的山寺夜游与叠层仍有各自价值。

优先新增沉淀：

1. **四季环境状态**：统一驱动植被、积雪、照明和雾色，核对叶片与阴影的一致性。
2. **构造拆解与注释**：部件展开、观察镜头与投影标注，迁移到建筑、机械和产品讲解。
3. **加载与绘制调度**：分批让出主线程、预热纹理／着色器／几何，按章节请求和重绘；收益需要同设备测量。

第二批研究背景感知导航、材料图像叙事、镜头交接与合成声景。水面、AO、通用后期和植被受光可对照已有 [009 光照研究](../009-webgpu-render-pipeline/README.md)，降低重复研究优先级。材料照片章节属于二维转场；积雪和焦散是视觉规则或近似。

## 本地运行

在仓库根目录执行：

```powershell
python projects/014-seijaku/scripts/package_web.py
python projects/014-seijaku/scripts/verify_web.py
python -m http.server 8054 --bind 127.0.0.1
```

打开 [研究网页](http://127.0.0.1:8054/projects/014-seijaku/web/)。ES modules 需要通过 HTTP 加载。文字与自有图解从本地读取，官方图片和体验需联网。启动后在画面内滚动，或使用“独立打开”；切换项目、结束体验会卸载前一 iframe。
